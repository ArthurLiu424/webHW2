PHASE 1 · BUSINESS UNDERSTANDING

問題定義

洪水是造成財產與人命損失最頻繁的天然災害之一。地方政府與保險公司需要一個可解釋的工具：給定一個區域在季風強度、排水系統、都市化、森林砍伐等 20 項因子的評分（0–18 分整數），估計該區發生洪水的機率，並且清楚說明估計的不確定程度。

  • 預測目標：FloodProbability（連續值，約 0.32–0.73）。
  • 成功指標：測試集 R² ≥ 0.80、RMSE 越低越好；95% 預測區間實際覆蓋率接近 95%。
  • 為何用線性回歸：係數可直接解讀為「某因子每增加 1 分，洪水機率增加多少」，便於決策者溝通。

PHASE 3 · DATA PREPARATION

資料準備

  • 移除 id 欄位；檢查缺失值與重複列（皆為 0，無需填補）。
  • 所有特徵皆為整數評分，不需要類別編碼。
  • 以固定亂數種子（seed=42）切分 80% 訓練 / 20% 測試；特徵選擇與交叉驗證只使用訓練集，避免資料洩漏。
  • 標準化（z-score）只用訓練集的平均與標準差，供 Lasso 與標準化係數比較使用；最終模型以原始尺度訓練，係數易於解釋。
  • 另建工程特徵 FeatureSum＝20 個因子總和，作為簡單線性回歸對照組。
PHASE 4 · MODELING & FEATURE SELECTION

特徵選擇與建模

使用四種特徵選擇方法互相驗證：(a) Filter：單變量 F-test（等同 SelectKBest(f_regression)）；(b) Wrapper：前向逐步選擇，以 5-fold CV RMSE 為準則；(c) Embedded：Lasso 路徑；(d) 後向淘汰（p-value > 0.05 即刪除）。

NotebookLM 摘要

網路上同主題解法研究

【請貼上 NotebookLM 產生的摘要】建議匯入的來源：Kaggle Playground S4E5 的 Discussion 與高票 Notebook、原始 Flood Prediction Dataset 的 Code 頁面。報告初稿（請以 NotebookLM 實際輸出核對後取代）：在 Kaggle「Regression with a Flood Prediction Dataset」(Playground S4E5) 中，評分指標為 R²。多數公開解法發現，20 個風險因子與目標之間幾乎是等權重的線性關係，因此單純的線性回歸就能達到約 0.84–0.85 的 R²。進一步的改進多來自特徵工程：加入 20 個特徵的總和、平均、標準差、最大最小值、排序後分位數等列統計量，再搭配 LightGBM、XGBoost、CatBoost 等梯度提升樹或神經網路進行集成，可將 R² 提升到約 0.869。也有作者指出原始 flood.csv 幾乎沒有雜訊，而競賽資料是由生成模型合成，因此帶有額外雜訊。本作業的結果與這些觀察一致：只用 FeatureSum 的簡單線性回歸，R² 就與 20 特徵的多元回歸相同。

資料來源：Kaggle · naiyakhalid/flood-prediction-dataset（train.csv，隨機抽樣 50,000 筆，seed 2024）。所有數值皆由 analysis.py（numpy / scipy）計算後寫入 docs/data.js。
